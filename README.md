# 📋 工作看板（Work Dashboard）

一个**零依赖、开箱即用**的个人工作看板：纯 HTML + CSS + 原生 JavaScript 实现，无需安装任何东西，双击 `index.html` 即可使用，数据自动保存在浏览器本地。

## ✨ 功能特性

### 核心看板
- **阶段看板**：规划 → 执行 → 监控 → 完成 四列，**拖拽卡片即切换阶段**
- **优先级**：高 / 中 / 低三级，单击标签循环切换，红/黄/绿语义色
- **列表 / 卡片双视图**：一键切换，列表视图所有字段支持内联编辑
- **快捷修改零负担**：双击改标题、单击改截止日期、拖拽改阶段，全部 1~2 步完成

### 项目与任务层级
- **三级结构**：项目 → 任务 → 子任务
- **独立任务**：不属于任何项目的任务单独分组显示
- **两种新建方式分开**：项目行上的 ＋ 在项目下建任务；顶栏/独立分组的 ＋ 建独立任务
- **删除项目**会连同其下任务一起删除（有确认提示）

### 总览与时间轴
- **统计卡片跟随选择**：点项目显示项目数据，点任务显示任务详情（倒计时/子任务进度/优先级/阶段/归属）
- **甘特图式时间轴**：项目显示进度胶囊条，任务显示 ◆ 截止日里程碑，红色虚线标记"今天"
- **日 / 周 / 月 / 年 四种粒度**切换时间窗口
- **任务详情面板**：子任务的勾选完成、回车新增、删除

### 效率工具
- **今日待办**（右侧栏）：备忘录式录入，输入回车即添加，勾选即完成
- **即将到期**（右侧栏）：未来 7 天内截止任务汇总
- **粘贴导入**：从 Excel / WPS / 网页表格复制后粘贴，自动识别任务标题、时间节点、优先级、阶段及其他附带信息，预览后一键导入
- **数据持久化**：所有操作即时保存到浏览器 localStorage，刷新不丢失

## 🚀 快速开始

无需任何环境，直接双击打开：

```
双击 index.html 即可
```

或使用任意静态服务器（可选）：

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 🌐 部署方式

本项目是纯静态站点，可托管到任何静态托管服务：

### GitHub Pages
1. 将仓库推送到 GitHub
2. 仓库 Settings → Pages → Source 选择 `main` 分支 / `root`
3. 稍等片刻即可通过 `https://<用户名>.github.io/<仓库名>/` 访问

### Vercel / Netlify
导入本仓库即可自动部署，无需任何配置。

## ⚠️ 数据说明

- 任务数据保存在**每个访问者自己浏览器的 localStorage** 中，不同设备、不同浏览器、不同用户之间的数据**互相独立、不会同步**
- 如需多人共享同一份数据或跨设备同步，需要接入后端存储（当前版本为纯前端实现）

## 📱 兼容性

- 现代浏览器均可使用（Chrome / Edge / Firefox / Safari）
- 响应式布局：桌面端三栏（导航 + 主区 + 待办栏），窄屏自动折叠堆叠，手机可用
