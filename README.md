# 📋 工作看板（Work Dashboard）

一个**零依赖、开箱即用**的个人工作看板：纯 HTML + CSS + 原生 JavaScript 实现，无需安装任何东西，双击 `index.html` 即可使用，数据自动保存在浏览器本地。

## ✨ 功能特性

### 核心看板
- **阶段看板**：规划 → 执行 → 监控 → 完成 四列，**拖拽卡片即切换阶段**
- **优先级**：高 / 中 / 低三级，单击标签循环切换，红/黄/绿语义色
- **列表 / 卡片双视图**：一键切换，列表视图所有字段支持内联编辑
- **快捷修改零负担**：双击改标题、单击改截止日期、拖拽改阶段，全部 1~2 步完成

### 项目与任务层级
- **三级结构**：项目 → 任务 → 子任务
- **独立任务**：不属于任何项目的任务单独分组显示
- **两种新建方式分开**：项目行上的 ＋ 在项目下建任务；顶栏/独立分组的 ＋ 建独立任务
- **删除项目**会连同其下任务一起删除（有确认提示）

### 总览与时间轴
- **统计卡片跟随选择**：点项目显示项目数据，点任务显示任务详情（倒计时/子任务进度/优先级/阶段/归属）
- **甘特图式时间轴**：项目显示进度胶囊条，任务显示 ◆ 截止日里程碑，红色虚线标记"今天"
- **日 / 周 / 月 / 年 四种粒度**切换时间窗口
- **任务详情面板**：子任务的勾选完成、回车新增、删除

### 效率工具
- **今日待办**（右侧栏）：备忘录式录入，输入回车即添加，勾选即完成
- **即将到期**（右侧栏）：未来 7 天内截止任务汇总
- **📅 侧栏日历**：彩色月视图，今天渐变高亮、周末橙色，有任务截止的日期按优先级显示彩色圆点，悬停查看任务名，支持翻月
- **⏳ 倒计时**（右侧栏）：设了截止日期的任务/项目自动进入（任务带优先级圆点，点击可定位），也可手动插入自定义倒计时；全部按到期时间升序排列，剩余天数与时分秒逐秒跳动，到期红色警示/到达 🎉 提醒，随云同步多设备共享
- **💬 意见反馈**：右下角悬浮按钮，意见直达开发者数据库（可匿名，选填联系方式）
- **粘贴导入**：从 Excel / WPS / 网页表格复制后粘贴，自动识别任务标题、时间节点、优先级、阶段及其他附带信息，预览后一键导入
- **数据持久化**：所有操作即时保存到浏览器 localStorage，刷新不丢失
- **☁️ 多设备云同步**：基于 Supabase，电脑/平板/手机填写同一个同步码即可共享同一份数据（详见下方说明）
- **界面**：功能入口全图标化（侧栏/看板列头/按钮/弹窗标题），所有弹窗右上角统一 ✕ 关闭按钮，支持点遮罩或 Esc 关闭

## 🌐 部署方式

本项目是纯静态站点，可托管到任何静态托管服务。

**当前线上地址（Netlify）**：<https://resplendent-gelato-8fe680.netlify.app>

Netlify 已绑定 GitHub 仓库，每次推送代码后自动重新部署，无需手动操作。

### Netlify（当前使用）
1. `app.netlify.com` 用 GitHub 登录 → Add new site → Import an existing project
2. 选择本仓库，部署设置全部默认 → Deploy site
3. 注意：若站点返回 401，到 Project configuration → General → Visitor access 将可见性改为 Public

### GitHub Pages（备用）
1. 将仓库推送到 GitHub（仓库必须为 Public，私有仓库会停用 Pages）
2. 仓库 Settings → Pages → Source 选择 `Deploy from a branch`，分支选 `main` / `root` 并保存
3. 稍等片刻即可通过 `https://<用户名>.github.io/<仓库名>/` 访问

## ☁️ 多设备云同步（电脑 / 平板 / 手机同一份数据）

看板支持可选的云同步，让多台设备看到完全相同的数据：

### 使用方法

1. 打开看板 → 顶栏点「☁️ 同步」
2. 点「🎲 生成」得到一个**同步码**（相当于数据密码），点「保存并连接」
3. 其他设备打开同一链接 →「☁️ 同步」→ 填入**相同的同步码** → 保存并连接，即可载入全部数据
4. 之后任何设备的修改会自动上云，其他设备刷新页面即见最新内容；弹窗内可随时「断开同步」

### 同步机制

- **双层存储**：本地 localStorage 即时保存（离线可用），云端 Supabase 负责跨设备同步，网络异常时不影响本地使用
- **自动推送**：停止操作约 1.5 秒后自动写入云端，无需手动操作
- **智能合并**：打开页面时云端与本地按时间戳比对，新者为准；新设备接入时云端已有数据一律以云端为准，不会被新浏览器的示例数据覆盖
- **数据隔离**：不同同步码的数据完全隔离、互不可见：
  - 只把链接发给别人 → 对方用自己生成的同步码，数据各归各
  - 链接 + 同一个同步码一起发 → 多人共享同一块看板（适合家庭/情侣/搭桌共用）

### 注意事项

- 同步码等同密码，持有者可查看、修改、删除全部数据，只发给信任的人；建议自行备份记录，丢失后无法找回云端数据
- 同步采用“整份覆盖”策略：多人同时修改时以后写入者为准，适合轻量共用，不适合多人高频并发编辑
